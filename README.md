# 澄海3C 改建（AutoHotkey v2）

魔兽争霸 3 RPG 地图《澄海3C》的按键改建工具。用 AutoHotkey v2 写成，**不联网、不读游戏内存、不注入进程**，只做两件事：点屏幕上的固定位置、发按键。

> 为什么自己写：网上流传的 3C 改建工具大多是十几年前的论坛作品，常被二次打包绑马（本项目的诞生就是因为原工具被查出蠕虫病毒）。这个项目全程可逐行审阅，源码就这些，没有可疑行为。

## 它能做什么

| 模块 | 作用 |
|---|---|
| 技能栏改建 | Q W E R T → 点技能栏 1~5 格，可选"举起后自动点鼠标位置"一步施法 |
| 物品栏改建 | C V B N / Z X → 点物品栏 1~6 格，同样支持自动补点 |
| 闪现连招 | 空格 → 点匕首 → 点鼠标位置 → 接践踏，一键完成（带防连按） |
| 回城 | F 道具回城 / G 技能回城，自动点小地图本方基地 |
| 切英雄 | 鼠标侧键循环切换；传送后按编队键自动选中指定英雄 |
| 保持原位 | 鼠标中键 → H |
| 血量检测 | F11 → 抓帧读 5 个英雄血条，用提示音分三档报告 |
| 物品整理 | F5 登记布局 / F6 自动归位（抓帧 + 图标指纹比对） |
| 无边框全屏 | F9 |

## 原理

不读内存、不拦截网络包，全部基于两种手段：

1. **坐标点击** —— 校准时记录技能栏/物品栏/头像的屏幕坐标，按键时点过去（可选冻结物理输入几十毫秒，避免和你的鼠标抢位置）
2. **抓帧识别** —— 用 ffmpeg 的 `ddagrab` 抓一帧（约 0.4 秒），在内存里切块比对。用于物品整理、英雄头像识别、血条读取

因为不碰内存和封包，所以不会被反作弊盯上；代价是每次识别有 0.4 秒延迟，只能用于非实时场景。

## 安装

1. **AutoHotkey v2** — https://www.autohotkey.com/
2. **Python 3.9+** — 只用标准库，无需 pip 装任何东西
3. **ffmpeg** — 需要 `ddagrab`（DXGI 桌面复制），放 PATH 里

## 使用

```
1. 双击 澄海3C改建.ahk（会弹 UAC，必须点"是"——游戏通常以管理员运行，权限不对等会拦截模拟输入）
2. 进游戏，按 F8 校准：按提示把鼠标移到各个格子上按空格，依次记录
3. 坐标存在 3C改建.ini 里，换分辨率要重新校准
```

首次使用建议先看 `3C改建.ini` 里的配置项，很多行为可以调（是否自动补点、等待时间、切人方式等）。

## 键位

| 键 | 作用 |
|---|---|
| Q W E R T | 技能 1~5 |
| C V B N | 物品 1~4 |
| Z X | 物品 5~6 |
| 空格 | 闪现 + 践踏（用第 6 格的匕首） |
| F / G | 道具回城 / 技能回城 |
| Delete | 切换光盟 / 黑暗 |
| 鼠标中键 | H（保持原位） |
| 鼠标侧键 | 切上一个 / 下一个英雄 |
| F5 / F6 | 登记标准布局 / 自动整理物品 |
| F8 / F4 | 完整校准 / 只校准英雄头像 |
| F11 | 查血量 |
| Insert | 暂停（暂停时按键原样放行） |
| Ctrl+F10 | 强制退出魔兽 |
| Ctrl+F7 | 切换点击方式（消息投递 / 物理点击） |

## 已知限制

- **屏幕坐标绑定**：换分辨率、改窗口大小、动过 UI 缩放都要重新校准
- **识别有 0.4 秒延迟**：抓帧成本决定的，所以只用在"整理物品""查血量""传送判定"这类非实时场景
- **指哪打哪靠鼠标位置**：自动补点的落点 = 你按键那一刻的鼠标位置，不是智能判断
- **游戏更新可能失效**：地图改版后格子位置、头像、图标都会变，需要重新登记

## 免责声明

- 不做自动打钱、自动施法、透视、读对方位置这类功能（也不需要）
- 对局平台的反作弊策略各有不同，使用前请自行确认是否符合平台规则
